Pipeline

How it works

Every prediction runs through the same five-stage path, from your browser to the trained model and back.

  1. 01

    Student data

    You enter demographic, social media, lifestyle and stress information into the form.

  2. 02

    FastAPI

    The frontend sends that data as JSON to the FastAPI /predict endpoint.

  3. 03

    Preprocessing pipeline

    The saved pipeline scales numeric fields and applies ordinal and one-hot encoding, matching how the model was trained.

  4. 04

    Regression model

    The trained model generates a predicted mental health score from the processed input.

  5. 05

    Result

    The score returns as JSON and is displayed here, in the animated result card.
