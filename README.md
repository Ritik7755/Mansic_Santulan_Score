
# 🧠 Student Mental Health Predictor

A full-stack machine learning web application that uses student lifestyle, social media usage,
academic habits, sleep, physical activity, stress levels,
and demographic information to generate a model-based mental health score.

The project takes a trained machine learning model beyond a notebook and turns it into an interactive, 
user-friendly web application with a FastAPI backend and deployed REST API.

## 🚀 Key Features

- 🤖 Machine Learning Prediction
- 📝 Interactive Prediction Form
- ⚡ FastAPI Backend
- 🛡️ Pydantic Data Validation
- 📊 Scikit-learn Regression Model
- 🔄 Frontend–Backend REST API Integration
- 📈 Interactive Prediction Visualization
- 🌙 Dark / Light Mode
- 📱 Fully Responsive UI
- 🟢 API Health Status Monitoring
- ⚠️ Input Validation & Error Handling
- ✨ Smooth Animations & Interactive UI
- 🔄 Loading States for API Requests
